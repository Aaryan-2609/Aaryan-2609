### 🤖 AI-Powered Self-Healing AIOps Platform

An intelligent infrastructure operations platform that monitors cloud resources, analyzes incidents, and automates recovery.

**Key highlights**

- Real-time infrastructure monitoring with Prometheus, Alertmanager, and Grafana.
- AWS EC2 service discovery and exporters for CPU, memory, disk, network, and service metrics.
- RAG-based root cause analysis using ChromaDB, system logs, live metrics, SSH-collected evidence, and troubleshooting runbooks.
- Automated Nginx remediation with recovery verification.
- AI-generated incident reports and Slack notifications.

**Built with:** `AWS EC2` `Prometheus` `Grafana` `Python` `Flask` `ChromaDB` `OpenAI API` `Slack`
